# 1ab1_md_ss_compare
This repository contains input files, scripts, and results for simulating the small protein 1AB1 using GROMACS
With disulfide bridges - 1AB1_ss
Without disulfide bridges - 1AB1_noss

md.sh (in 1AB1_ss and  1AB1_noss) — Bash script to run MD for both cases (interactive prompt: Y/N for disulfide)
